# Security

`skill-manifest-audit-skill` is a local-first, read-only CLI for inspecting repository files supplied by the operator.

## Reporting

Please report security issues through GitHub private vulnerability reporting when available, or open a minimal issue that avoids sensitive details.

## Boundaries

- Do not include private repository contents, credentials, or unreleased skill details in public issues.
- The CLI should not require network access or secrets.
- Keep future fixer modes opt-in and dry-run first.
